PaletteIQ → Canva

1. In PaletteIQ select images, click Send to Canva, then paste a task pairing code below.

2. In Canva open a design and Uploads. Confirm the uploaded image appears, place and select it on the canvas, then click Run Canva Upscale. If Edit image opens first, click Run Canva Upscale again. Wait for the overlay to clear. Export the selected image as PNG with transparency.

3. Choose the Canva result below to save it back to the original PaletteIQ collection. Chrome does not grant extensions unrestricted access to downloaded local files, so this return step still needs file selection.

v3 test: Works with PaletteIQ Web :5173 or Desktop :18763. Pairing expires after 30 minutes. Original files are preserved.
